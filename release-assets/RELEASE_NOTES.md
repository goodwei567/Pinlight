# Pinlight v0.3.9

Windows 10/11 x64 screenshot and pin utility.

## Highlights

- Added an optional **Start with Windows (tray)** setting. It uses a per-user startup entry, requires no administrator permission, and starts Pinlight quietly in the system tray.
- Existing startup entries follow the currently opened build after upgrading.
- Refined the capture selection and annotation toolbars while preserving the existing compact dark-blue design.
- Reduced startup flicker by completing the main window's first paint off-screen.
- Added 3, 5, and 10 second delayed-capture choices.
- Scrolling capture samples continuously and updates a live side preview.

## Installation

Download `Pinlight-v0.3.9-win-x64.zip`, extract it, and run `Pinlight.exe`.

Requires .NET Framework 4.8. No administrator privileges are required.
