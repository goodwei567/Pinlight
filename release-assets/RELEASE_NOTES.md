# Pinlight v0.3.2

Windows 10/11 x64 screenshot and pin utility.

## Changes

- Scrolling capture now samples about every 30 ms instead of waiting for the screen to stop moving.
- Faster matching supports continuous scrolling and smaller frame overlaps.
- The live side preview uses an incremental cache, so it updates with each stitched frame.
- Exported PNGs remain pixel-exact at the original screen resolution.

## Installation

Download `Pinlight-v0.3.2-win-x64.zip`, extract it, and run `Pinlight.exe`.

Requires .NET Framework 4.8. No administrator privileges are required.
